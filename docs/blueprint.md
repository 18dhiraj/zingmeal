# **App Name**: MealFinder

## Core Features:

- Homepage Form: Home page featuring a three-step form: price range (slider), dietary preferences, and meals per day.
- Database Query: Dynamically query Firebase Database based on user inputs for meal recommendations.
- Meal Display: Display meal recommendations on the page with details. Integrate with firebase storage to display meal image.
- Meal Swap: Implement a 'Swap' button to fetch the next available meal with the same applied filters.

## Style Guidelines:

- Primary color: Soft blue (#64B5F6) for a calming and trustworthy feel, evoking a sense of healthy eating.
- Background color: Light grey (#F0F4F8), almost white, for a clean and modern interface.
- Accent color: Orange (#FFB74D) for buttons and interactive elements to draw attention.
- Font pairing: 'Manrope' (sans-serif) for headlines and 'Manrope' (sans-serif) for body text, offering a modern yet readable combination.
- Use simple, outlined icons related to dietary preferences and meal types for easy recognition.
- Maintain a clean, card-based layout for meal display, with clear separation of information and an image.
- Subtle transitions when swapping meals for a smooth user experience.
